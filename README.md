# Hiking MCP Server

Serveur MCP pour assister dans la planification de randonnées.

## Fonctionnalités
- **search_hikes** : Recherche de sentiers via Overpass API.
- **get_weather_forecast** : Prévisions météo via Open-Meteo.
- **get_nearby_pois** : Recherche de points d'intérêt (viewpoints, shelters, fast food).

## Installation
```bash
pip install mcp httpx
python server.py
```
